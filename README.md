# Minor-vCodex

Minor is a quiet decision-making tool that helps you let go of what matters less, so the few things that truly matter can rise to the surface.

Inspired by the Pareto principle, it turns scattered wishes into no more than three priorities—and keeps them close as a personal wallpaper.
